# LocalDevBadges

Vencord **userplugin** that lets you toggle three official-looking profile badges on **your own** profile — visible **only in your Discord client**.

| Badge | Toggle in plugin settings |
|-------|---------------------------|
| Discord Staff | Discord Staff |
| Early Verified Bot Developer | Early Verified Bot Developer |
| Active Developer | Active Developer |

Author: **Nandak070** (`1219803151180370021`)

## Important

- **Cosmetic / local only.** Does not grant real Discord badges. Other people (even with Vencord) will not see these badges on your profile unless they run the same settings on their own account for themselves.
- Client mods are unofficial. Use at your own discretion.

## Install

See **[INSTALL.md](./INSTALL.md)** for full steps (build Vencord from source + `userplugins`).

## Usage

1. Settings → **Vencord** → **Plugins** → enable **LocalDevBadges**
2. Open the plugin settings and turn on the badges you want
3. Open your profile — badges appear with official Discord icons
